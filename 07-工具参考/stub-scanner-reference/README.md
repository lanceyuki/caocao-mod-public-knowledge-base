# 特技桩扫描器参考实现

这是从工具箱桩扫描模块整理出的只读参考实现，包含 PE32 读取、调用目标扫描、桩参数候选解析和配置循环桩分析。它不修改输入文件，也不包含工具箱界面、补丁注入器、引擎文件、代码洞配置或资源资产。

你可以在本知识库非商业许可下克隆仓库或 Fork，并在本地副本中改造这组脚本用于自己的非商业开发；克隆和改造仍须保留许可要求，任何商业用途均禁止。

## 适用范围

识别规则是从一个 6.5pl 样本的分析经验中提炼的示例。它可以帮助开发者理解扫描流程，并作为适配自己引擎副本的起点；不保证不同引擎版本能够直接运行，也不保证结果完整或正确。PE 文件布局、调用目标、桩指令形态和参数含义均应按目标样本重新确认。

当前参考实现只覆盖可由配置目标识别、且符合所列指令模式的桩候选。源码定义或仅靠代码洞签名识别的格式不在本包中，因为这类识别依赖目标专属位置和布局。扫描结果不是玩法或运行时验收结论。

## 运行

需要 Python 3 和 Capstone。安装依赖后，复制 `profile.example.json` 并填写目标文件的调用目标范围或内联核心地址：

```text
python -m pip install -r requirements.txt
python scan_engine.py path/to/your-engine.exe --profile your-profile.json
```

配置中的地址是用户针对自己样本填写的虚拟地址，不应直接沿用其他样本的地址。示例文件故意不含目标地址，因此须先完成配置才能扫描。

```json
{
  "dispatch_ranges": [
    {"start": "0xSTART", "end": "0xEND", "label": "your dispatch range"}
  ],
  "inline_core_targets": ["0xTARGET"],
  "dispatch_body": null,
  "skill_name_table_va": null
}
```

- `dispatch_ranges`：需要纳入搜索的目标地址区间，左闭右开；标签只用于标记输出来源。
- `inline_core_targets`：直接调用的内联核心地址。
- `dispatch_body`：可选的调度代码区间，用来过滤该区间内部的调用记录。
- `skill_name_table_va`：可选的名称表起始虚拟地址；CLI 按每项 16 字节、GBK 编码读取候选个人特技名。若自己的名表步长或编码不同，应修改 `get_skill_name` 后再核对输出。

输出为 JSON，包含候选调用位置、目标、参数解释、可定位的立即数位置及配置循环范围。应回到反汇编器检查调用前后控制流，并用目标文件的原始字节复核地址与字段；若模式不同，应修改扫描规则或另写适配器。

## 维护和限制

本参考实现保留了工具箱中已使用的若干 32 位 x86 指令模式，但其参数解释依赖样本结构。它可能漏掉未配置的目标、不同编译器生成的桩、跨函数参数准备、间接调用以及被移除的源码定义格式，也可能把相似指令序列误报为候选。使用者应记录自己的样本范围、修改内容和验证证据。

本文件夹只发布扫描算法参考代码及其依赖声明。它不是完整工具箱，也不提供目标引擎、引擎资产、项目私有地址表或代码洞清单。所有用途均受仓库根目录的非商业使用许可约束，商业用途禁止。
