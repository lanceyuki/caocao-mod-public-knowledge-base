# 普通物理路径中的攻击侧值与 MP 加成

> **样本范围：** 本文整理 6.5pl 分析样本中的普通物理攻击路径。地址和偏移只用于复查该样本；其他构建须自行定位。本文记录静态调用链和有限的运行时读值，不给出完整伤害公式，也不代表游戏内效果已全面验收。

## 结论摘要

- 在该样本中，`DataRecord+0x11` 是 word 原始攻击属性；战术单位 `TacticalUnit+0x14` 是当前 MP 字段。它们属于不同对象和不同用途。
- 普通物理路径中的“炼气成刃”会按特效值计算 MP 加成，并把加成加入属性选择器的第 0 项候选。该候选还要经过后续选择与修饰，不能当成最终攻击侧值。
- 攻击状态档位位于战术单位 `+0x18`，正常值为 `3`。它是状态档位，不是最终攻击力总值。
- 已追踪路径将修饰后的攻击侧结果放入调用帧局部变量，再与防御侧值进入伤害算术；本路径没有观察到将最终攻击力写回战术单位结构。

## 取值与加成路径

1. 属性选择器的第 0 项通过样本函数链 `0x43F5FF → 0x40658F → 0x4061E4` 获取 `DataRecord`。该样本以 `[0x4CEA00] + DataID × 0x48` 定位记录；`0x4E45AA` 从记录 `+0x11` 读取 word 原始攻击属性。
2. “炼气成刃”的效果值计算链通过 `0x472840` 读取战术单位 `+0x14` 的当前 MP，再按特效值换算加成。其调用方在 `0x414D33` 取此加成，并于 `0x414D39` 加入第 0 项候选。
3. `0x414D39` 的结果只是一个候选值。选择器还会比较其他候选，之后普通物理路径再对所选结果施加修饰。
4. 样本中的 `0x40D2B2` 在 `0x40D33B` 通过 `EDX` 返回修饰后的攻击侧值；调用方于 `0x43BD06` 将其保存到 `[ebp-0x20]`。这是当前调用帧的局部值，不是单位结构偏移。
5. 从 `0x43BD3A` 起，攻击侧局部值与防御侧局部值 `[ebp-0x10]` 一同进入伤害基数计算。本文没有重建之后的完整伤害公式。

## 如何区分几个“攻击”相关值

| 值 | 样本位置 | 含义与边界 |
|---|---|---|
| 原始攻击属性 | `DataRecord+0x11`，word | 属性选择器第 0 项的基础输入之一；成长、装备和其他修饰可能继续影响 getter 结果 |
| 当前 MP | `TacticalUnit+0x14`，dword 字段 | “炼气成刃”的样本取值函数读取 `word [unit+0x14]`，即低 16 位；不是原始攻击属性 |
| 攻击状态档位 | `TacticalUnit+0x18` | 属性状态值，正常档位为 `3`；不是攻击力总值 |
| 攻击侧调用结果 | `[ebp-0x20]` | 普通物理路径中，后续修饰后的调用帧局部值；不是持久字段 |

## 证据范围

- **静态分析：** 支持上述对象区分、读取顺序、MP 加成进入第 0 项候选，以及攻击侧局部值进入后续伤害算术的普通物理路径。
- **运行时读值：** 一个观察样本支持 `0x472840` 在该调用中读取当前战术单位 MP；这不能证明该函数的其他调用点都处于同一语境。
- **尚未确认：** 完整伤害公式、所有攻击入口是否共用此路径、其他分支是否另存最终攻击值，以及精确游戏效果。

使用者应在自己的目标上重新核对函数边界、对象类型、调用约定、候选选择顺序和最终消费者。

战场单位、角色配置、Data 记录和调用帧局部值的区别见[对象类型与编号转换](../02-数据结构/object-identifiers-and-records.md)。
