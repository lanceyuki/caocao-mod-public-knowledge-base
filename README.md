# 曹操传 Mod 公共知识库（候选包）

本包收录可复用的引擎分析方法、Win32 控件追踪指南、二进制开发/调试 skills，以及从工具箱中整理出的只读扫描脚本参考，供 Mod 作者在自己的开发工作中参考。

> **适用范围声明：** 引擎分析内容和工具脚本基于 6.5pl 样本与开发经验整理，不保证绝对正确，也不保证适用于所有引擎；内容仅供参考，请谨慎使用。样本地址只作为定位线索，使用者应在自己的目标文件上重新核对。工具脚本可以作为实现思路和适配起点，使用者可按自己的引擎样本修改配置或扫描逻辑；本库不承诺不同版本能够直接运行或稳定适配。

## 推荐阅读顺序

1. 先看[二进制引擎开发方法总览](./00-方法论/README.md)，了解从行为契约、调用链追踪到分层验收的主线。
2. 进行新增、修改、移植或故障定位时，按[经典战棋引擎功能开发与移植](./06-可复用Skills/engine-feature-development/SKILL.md)执行具体步骤。
3. 需要运行时证据时，参考[x32dbg/x64dbg 动态调试](./06-可复用Skills/x32dbg-debugging/SKILL.md)；分析 Win32 界面时，参考[控件追踪方法](./05-教程指南/win32-control-tracing.md)。
4. 先看[对象类型与编号转换](./02-数据结构/object-identifiers-and-records.md)，再通过核心分析页和样本机制页查看方法如何应用，并按页面中的样本范围和未知边界复核。
5. 如需自动枚举特技桩候选，可阅读[特技桩扫描器参考实现](./07-工具参考/stub-scanner-reference/README.md)。它需要用户为目标样本填写地址配置，扫描结果仍须逐项复核。
